# MicroARCA

Site público do projeto MicroARCA — Aprendizado, Robótica e Computação Acessível.

O MicroARCA permite programar um ESP32 com MicroPython pelo celular Android,
usando blocos ou Python, com envio de programas por Bluetooth Low Energy.

Este repositório reúne a página pública e os documentos do projeto.
